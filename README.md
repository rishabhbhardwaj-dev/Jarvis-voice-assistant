# 🤖 JARVIS AI Assistant

A real-time AI-powered desktop assistant built using Python, Flask, and Groq LLMs with voice automation, conversational AI, and intelligent system control capabilities.

---

## 🚀 Features

- 🎙️ Voice command processing
- 🧠 Conversational AI integration
- 🔊 Text-to-speech responses
- 👂 Wake word detection
- ⚡ Real-time command execution
- 🌐 Browser automation
- 🖥️ System monitoring and control
- 🧩 Interactive neural-interface dashboard
- 🔄 Sleep/Wake modes
- 📡 Live state synchronization using SSE

## 📌 Project Overview

JARVIS AI is an intelligent desktop assistant capable of understanding voice commands, interacting conversationally, automating tasks, and managing system-level operations in real time.

The project combines AI, automation, and interactive UI technologies to create a futuristic assistant experience inspired by modern AI systems.
